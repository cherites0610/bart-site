這是占位文字，不是真正的文章。它存在的唯一目的，是讓你在寫第一篇文章之前，先看到標題、段落、程式碼、引言與清單在頁面上長什麼樣子。

正文每行約 35 個全形字，行高 1.8。眼睛讀到行尾時，不需要走太遠才能換行；段落之間的空白，足夠讓人在長文中停一口氣。

## 段落與強調

一般段落用黑體，**粗體**用來標出真的重要的詞，*斜體*很少用，因為中文沒有真正的斜體。[連結](https://docs.astro.build)會帶底線，滑過時加深，鍵盤聚焦時有郵戳紅外框。

行內程式碼像這樣：`npm run build`，使用等寬字，底下有淡淡的底色。

### 清單

- 無序清單的項目符號用郵局綠。
- 每一項之間留一點空氣，但不鬆散。
- 巢狀清單：
  - 第二層縮排一階。
  - 還是容易掃讀。

1. 有序清單的數字用等寬字。
2. 步驟之間的順序有意義時才用。
3. 不然就用上面的無序清單。

## 程式碼

程式碼區塊在文章中橫向捲動，不撐破版面：

```ts
// 範例：計算閱讀時間（占位用）
export function readingMinutes(text: string, cpm = 400) {
	const chars = text.replace(/\s/g, '').length;
	return Math.max(1, Math.round(chars / cpm));
}
```

## 引言與分隔

> 引言用宋體，縮排並放大一點，像信裡被引用的一句話。它不需要左邊那條粗色線。
